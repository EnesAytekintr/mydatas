# MyDataS

MyDataS is a comprehensive data engineering tool designed to analyze, refactor, and visualize datasets efficiently. It allows users to generate statistical summaries, manage missing data, and create dynamic visualizations.

## 🚀 Features

### 📊 Data Analyzing
- **Column & Table Summary:** Statistical overviews for numerical data.
- **Mode Analysis:** Identification of the most frequent values for both categorical and numerical columns.
- **Missing Value Tracking:** Quick counting and filtering of NaN values.

### 🛠️ Data Refactoring
- **Advanced Cleaning:** Threshold-based row and column deletion.
- **NaN Handling:** Fill missing values with constants or drop them entirely.
- **Structure Updates:** Column renaming, deletion, and duplicate removal.

### 📈 Data Visualizing
- **Categorical Analysis:** Dynamic bar charts based on sum, mean, or standard deviation.
- **Distributions:** Histograms for understanding data spread.
- **Relational Plots:** Scatter plots with hue support for multi-dimensional analysis.
